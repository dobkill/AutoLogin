# network_service — 网络服务模块

> 模块类型：核心服务模块  
> 对应 UI：无（后台服务）  
> 依赖：Datas  
> 目录：`include/network_service/`、`src/network_service/`（待新建）

---

## 职责

封装所有 **网络底层能力**，包括网卡信息扫描、网络状态监控、指定 IP 发起请求。为 login_engine 和 network_page 提供网络层面的服务支持。

---

## 功能列表

### 1. 网卡信息扫描
- 枚举本机所有网络接口
- 获取每个接口的详细信息：IP 地址、子网掩码、网关、DNS、MAC 地址
- 区分有线/无线接口类型
- 跨平台支持：
  - Windows：使用 `GetAdaptersInfo` / `GetAdaptersAddresses` API
  - Linux：读取 `/proc/net/` 或使用 `ioctl` / `getifaddrs`
- 将扫描结果写入 Datas

### 2. 网络连接状态监控
- 实时监控网络连接/断开状态
- 定时检测网络可达性（可配置检测间隔）
- 网络状态变化时通过 Qt 信号通知 login_engine
- 将网络状态写入 Datas

### 3. 指定 IP 发起请求
- 为 login_engine 提供「绑定指定网卡 IP 发起 HTTP 请求」的能力
- 实现方式：
  - Linux：通过 `SO_BINDTODEVICE` 绑定网络接口
  - Windows：通过绑定特定本地 IP 地址实现
- 支持检测指定网卡是否可用（已连接且 IP 有效）

### 4. 网络连通性检测
- 检测指定 URL 是否可达（HTTP 探测）
- Ping 指定 IP/域名
- DNS 解析检测
- 返回延迟和连通性结果

### 5. 网卡变化事件通知
- 网卡启用/禁用事件
- 网卡 IP 地址变化事件
- 新网卡插入/移除事件
- 通过 Qt 信号槽通知其他模块

## 提供的接口

```
// 扫描所有网卡信息，结果写入 Datas
scanNetworkCards() → NetworkCard[]

// 获取当前网络连接状态
getNetworkStatus() → NetworkStatus

// 绑定指定 IP 发起 HTTP 请求
bindAndRequest(ip: string, url: string, options: RequestOptions) → Response

// 检测指定 URL 是否可达
checkConnectivity(url: string) → ConnectivityResult

// 检测指定网卡是否可用
isCardAvailable(ip: string) → boolean

// 启动/停止网络状态监控
startMonitoring(intervalMs: int) → void
stopMonitoring() → void
```

---

## 信号通知

```
// 网卡列表变化（新增/移除/状态变化）
networkCardsChanged(cards: NetworkCard[])

// 网络连接状态变化（连接/断开）
networkStatusChanged(status: NetworkStatus)

// 指定网卡状态变化
cardStatusChanged(card: NetworkCard)
```

---

## 数据结构

```
NetworkCard:
{
  interfaceName: string,       // 接口名称
  ipAddress: string,           // IP 地址
  subnetMask: string,          // 子网掩码
  gateway: string,             // 网关
  dns: string[],               // DNS 服务器列表
  macAddress: string,          // MAC 地址
  isConnected: boolean,        // 是否已连接
  type: "wired" | "wireless"   // 有线/无线
}

NetworkStatus:
{
  isOnline: boolean,           // 整体网络连接状态
  primaryIP: string,           // 主要出口 IP
  lastChecked: datetime        // 最后检测时间
}

ConnectivityResult:
{
  isReachable: boolean,
  latencyMs: int,              // 延迟毫秒数
  error: string                // 错误信息（如有）
}
```

## 与其他模块的交互

| 调用方 | 场景 |
|--------|------|
| network_page | 用户点击「刷新网卡」，触发 `scanNetworkCards()` |
| login_engine | 执行登录时绑定指定 IP，调用 `bindAndRequest()` |
| login_engine | 自动登录调度前检测网络状态，监听 `networkStatusChanged` 信号 |
| Datas | 扫描结果和状态变化自动写入 Datas |
