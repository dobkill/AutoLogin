# login_engine — 登录引擎模块

> 模块类型：核心服务模块  
> 对应 UI：无（后台服务）  
> 依赖：Datas、network_service  
> 目录：`include/login_engine/`、`src/login_engine/`（待新建）

---

## 职责

封装所有 **登录执行逻辑**，包括 API 登录、WebView 登录、自动登录调度。是系统中最核心的业务模块。

---

## 功能列表

### 1. API 登录执行
- 根据 login_config 中的 API 配置构建 HTTP 请求（URL、Method、Headers、Body）
- 通过 network_service 绑定指定网卡 IP 发起请求
- 解析 HTTP 响应判断登录成功/失败
- 将登录结果（status、updatedAt）写回 Datas

### 2. WebView 登录执行
- 根据 login_config 中的 WebView 配置打开嵌入式 WebView
- 按照 operations 中定义的 XPath 操作流程自动执行操作序列
- 支持操作类型：
  - `click` — 点击指定元素
  - `input` — 向指定元素输入文本
  - `wait` — 等待指定元素出现或等待固定时间
- 通过页面元素检测或 URL 变化判断登录结果
- 将登录结果写回 Datas

### 3. 自动登录调度
- 定时检测网络连接状态（通过 network_service）
- 网络连接恢复时，自动触发所有 `enabled=true` 的站点登录
- 支持配置自动登录间隔（从 settings 读取）
- `--auto-login` 命令行参数启动时，执行静默登录后退出程序

### 4. 批量登录管理
- 支持一次性执行多个站点的登录
- 登录队列管理，支持串行/并行执行策略
- 登录进度通知和结果汇总

### 5. 登录状态检测
- 主动检测指定站点的当前登录状态
- API 登录：发送轻量级探测请求判断会话是否有效
- WebView 登录：检测关键页面元素是否存在
- 登录过期时自动触发重登录

### 6. 错误处理和重试
- 网络超时重试（可配置超时时间和重试次数）
- 登录失败重试（可配置重试次数和间隔）
- 所有错误记录到日志

## 与其他模块的交互

| 调用方 | 场景 | 调用方式 |
|--------|------|----------|
| home_page | 用户点击「一键全部登录」 | `login_engine.executeAll()` |
| login_page | 用户点击「测试登录」 | `login_engine.testConfig(config)` |
| loginManager_page | 用户对站点点击「立即登录」 | `login_engine.executeOne(id)` |
| loginManager_page | 用户对站点点击「登出」 | `login_engine.logoutOne(id)` |
| main.cpp | `--auto-login` 启动模式 | `login_engine.silentLogin()` |
| setting_page | 自动登录开关变化 | `login_engine.setAutoLogin(enabled)` |

---

## 提供的接口

```
// 执行单个站点登录
executeOne(siteId: string) → LoginResult

// 执行多个站点登录
executeBatch(siteIds: string[]) → LoginResult[]

// 执行所有已启用站点登录
executeAll() → LoginResult[]

// 测试配置（不保存，仅测试连通性）
testConfig(config: LoginConfig) → LoginResult

// 登出指定站点
logoutOne(siteId: string) → void

// 检测指定站点登录状态
checkStatus(siteId: string) → LoginStatus

// 启动/停止自动登录调度
setAutoLogin(enabled: boolean) → void

// 静默登录（--auto-login 模式）
silentLogin() → void
```

## 数据结构

```
LoginResult:
{
  siteId: string,
  success: boolean,
  message: string,         // 成功/失败描述
  responseCode: int,       // HTTP 状态码（API 登录）
  executedAt: datetime
}

LoginStatus:
{
  siteId: string,
  isLoggedIn: boolean,
  lastLoginTime: datetime,
  lastCheckTime: datetime
}
```
