# Datas — 数据中心模块

> 模块类型：数据模块  
> 对应 UI：无  
> 依赖：无（被所有模块依赖）  
> 目录：`include/Datas/`、`src/Datas/`

---

## 职责

为其他 7 个模块提供 **统一的数据读写接口**，负责数据的持久化存储（SQLite + JSON）和数据变化通知。

---

## 管理的数据实体

### 1. login_config（登录配置列表）

**API 登录配置：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识，自动生成 |
| type | string | 固定值 `"api"` |
| url | string | 登录接口 URL |
| method | string | 请求方法：GET / POST / PUT |
| args | object | 请求参数，键值对 `{key: value}` |
| headers | object | 自定义请求头，键值对（可选） |
| networkCard | string | 绑定的网卡 IP 地址 |
| remark | string | 备注名称 |
| status | string | 登录状态：`logged_in` / `not_logged_in` |
| enabled | boolean | 是否启用自动登录 |
| updatedAt | datetime | 最后更新时间 |

**WebView 登录配置：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识，自动生成 |
| type | string | 固定值 `"webview"` |
| urls | string[] | 需要访问的 URL 序列 |
| operations | object | 操作流程：`{url: {xpath: operation}}` |
| networkCard | string | 绑定的网卡 IP 地址 |
| remark | string | 备注名称 |
| status | string | 登录状态：`logged_in` / `not_logged_in` |
| enabled | boolean | 是否启用自动登录 |
| updatedAt | datetime | 最后更新时间 |

| 字段 | 类型 | 说明 |

### 4. settings（系统设置）

| 字段 | 类型 | 默认值 | 说明 |

## 提供的接口

### 数据读写
- `getLoginConfigList()` → 获取所有登录配置
- `getLoginConfig(id)` → 获取指定登录配置
- `saveLoginConfig(config)` → 保存/更新登录配置
- `deleteLoginConfig(id)` → 删除登录配置
- `getNetworkCardList()` → 获取网卡列表
- `updateNetworkCardList(list)` → 更新网卡列表
- `getNetworkStatus()` → 获取网络状态
- `updateNetworkStatus(status)` → 更新网络状态
- `getSettings()` → 获取系统设置
- `saveSettings(settings)` → 保存系统设置

### 数据变化通知
- `loginConfigChanged(id)` → 登录配置变化信号
- `networkStatusChanged()` → 网络状态变化信号
- `settingsChanged()` → 设置变化信号

### 数据持久化
- 使用 SQLite 存储结构化数据（login_config、networkCard）
- 使用 JSON 文件存储设置项（settings）
- `exportData(filePath)` → 导出所有数据
- `importData(filePath)` → 导入数据
