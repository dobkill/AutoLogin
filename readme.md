# 自动登录器

一个基于 **Qt / C++** 的跨平台桌面工具，支持 **API 登录** 与 **WebView 登录**，并支持 **指定本机 IP 发起请求**，用于解决多网卡环境下的登录问题。

---
## 核心特点
- **跨平台**：支持 Windows / Linux
- **双登录模式**：支持 API 登录、WebView 登录
- **指定 IP 登录**：适配多网卡设备，控制请求从指定 IP 发出
- **开机自启**：支持系统启动后自动运行
- **基础配置管理**：支持 JSON 配置
---

webView登录：记录用户登录流程，自动模拟用户操作，实现登录。
