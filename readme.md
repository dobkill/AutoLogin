# 自动登录器

## 项目简介

自动登录器是一个基于 **Qt / C++** 实现的跨平台桌面工具，支持在 Windows 和 Linux 环境下运行。

本项目用于在用户授权的前提下，对指定系统的登录流程进行自动化处理，减少重复登录操作，提高桌面端工具或内部系统的使用效率。

## 核心能力

项目支持两种登录方式：

### 1. API 登录

当目标系统提供明确、稳定的登录接口时，可通过 API 方式直接完成登录流程。

适用场景：

* 内部系统登录
* 自动化测试环境
* 已知接口参数的业务系统
* 登录流程相对稳定的系统

### 2. WebView 登录

当登录流程依赖页面交互或前端脚本时，可通过内置 WebView 打开登录页面，由用户完成一次正常登录，并记录登录过程中的相关请求。

该方式主要用于辅助分析登录流程，定位登录相关请求、脚本和必要参数，为后续自动化登录提供依据。

```text
自动登录器

├── WebView 登录模块
```

## 功能说明

* 支持 Windows、Linux 平台
* 支持 API 方式登录
* 支持 WebView 页面登录
* 支持登录请求记录
* 支持登录状态保存
* 支持系统启动后自动运行
* 支持基础配置管理
* 支持后续扩展不同站点或系统的登录适配

## 自启动能力

程序支持跟随系统启动自动运行。

不同平台采用对应的系统机制：

* Windows：支持注册表、启动目录或任务计划方式
* Linux：支持桌面自启动项或用户级服务方式

具体实现方式根据实际部署环境选择。

## 使用场景

本项目主要适用于以下场景：

* 内部系统自动登录
* 桌面端业务辅助工具
* 自动化测试环境
* 授权系统集成
* 需要重复登录的业务流程优化

## 安全边界

本项目仅用于合法、授权的系统环境。

项目不用于：

* 未授权访问
* 绕过验证码、MFA 或风控机制
* 批量撞库
* 抓取第三方用户数据
* 违反目标系统协议或法律法规的行为

涉及账号、密码、Cookie、Token 等敏感信息时，应进行安全存储和日志脱敏处理。
